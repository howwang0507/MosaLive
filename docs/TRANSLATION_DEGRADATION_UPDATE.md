# 翻譯失敗時保留原文

本次變更僅完成實作與程式閱讀，依指示未執行測試、未重新啟動服務、未推播 Git。

即時管線現在將翻譯的 HTTP、逾時與 RuntimeError 改為局部降級：清除不完整譯文、保留原文定稿、繼續確認音訊進度。每 session 暫停翻譯十五秒，之後有新字幕工作才重新嘗試。辨識失敗仍走原有錯誤路徑，取消工作也不會被當成翻譯降級。

新增 translation_unavailable 事件欄位。Chrome 覆蓋層及本機網頁在僅繁中模式下也會暫時顯示原文與恢復提示；成功翻譯後沿用使用者原本的語言顯示設定。不更换模型、不增加並發數、不重新辨識已完成音訊。若先前已產生部分譯文，失敗定稿會清除它，避免把半句當完整翻譯。

限制：第一次失敗仍可能等待原有逾時；此功能不是GPU資源隔離。服務整體未啟動或ASR故障無法藉此恢復。降級路徑會改變原本翻譯錯誤事件的驗收預期，後續必須補充／更新測試。以往PASS紀錄不代表本輪已通過。

另將專心閱讀偏好保存到既有本機字幕設定，下次開啟沿用。未引入新的套件或模型。
