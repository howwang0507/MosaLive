# 啟動與字幕閱讀穩定性

- 重複執行啟動器時，辨識現有 MosaSub 健康端點，重用既有服務並開啟本機頁面。未就緒時明確提示；其他程式占用連接埠仍不干預。
- 普通連線重試不再立即清空字幕；已顯示的字幕仍按原停留時間消失。
- 播放跳躍與換片仍立即清空字幕、重設音訊，避免過期字幕殘留。
- 定稿在停留期間不被下一句暫定結果覆蓋；下一句定稿可以立即替換它，不累積排隊字幕。
- 品質案例見 `quality/translation-regressions.json`。reference 是參考譯法，應按語意評估，不能要求字串完全一致。文字案例不能證明 ASR 正確率。

## 使用與驗收

更新 extension 檔案後，重新載入擴充套件並刷新影片分頁，再按「翻譯此分頁」。launch.py 修改於下次啟動套用。

依序檢查：本機 health → 收音是否啟動 → audio_samples 是否增加 → finals 是否增加 → 翻譯錯誤紀錄 → overlay 顯示模式。

語法與模擬測試不等於真模型推論或 Twitch 實播驗收。新版本需另確認斷線時定稿保留、換片立即清除、下一句定稿正常取代，並記錄品質案例修改前後的實際輸出。
