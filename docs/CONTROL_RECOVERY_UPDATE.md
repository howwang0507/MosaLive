# 收音控制與恢復更新

本輪依使用者要求自主改善，不執行測試、不啟動模型或監控、不推播 Git。

## 可見變更

- 面板新增「從現在重新接續」：經背景控制權限驗證後清除積壓音訊、前文與舊回呼，保留既有分頁收音授權。三秒節流避免連續點擊造成重設風暴；收音已結束時仍需重新授權。
- 四種情境設定：省運算（繁中定稿、不做二次校對）、閱讀（自動停留）、學語言（雙語八秒）、僅原文（省去後續翻譯）。沿用既有模型，無額外模型、並发或推論程序。省運算設定不會自動卸載模型；僅原文亦不保證 Ollama 立即釋放顯存。
- 情境設定與點擊穿透作用於實際收音分頁，避免面板開在另一頁時控制錯誤對象。
- 錯誤回報可保存最多兩千字人工修正；保留三十筆本機上限，不自動污染術語庫。
- 面板避免重疊輪詢，隱藏時跳過輪詢；GPU 查詢失敗不再掩蓋已取得的服務健康資訊。
- 啟動器在載入 ASR 前確認 Ollama 及指定模型；Ollama 未啟動時嘗試隱藏啟動，最多等待約二十秒。模型未安裝時明確停止，不自行下載。Ollama 為共用服務，不隨 MosaSub 停止。

## 生效與驗證狀態

尚未執行單元測試、瀏覽器驗收或真模型測試；也未重啟目前服务。需重啟啟動器、重新載入擴充套件與影音分頁後使用。本次是功能實作，不能視為已證明效能或可靠性改善。
