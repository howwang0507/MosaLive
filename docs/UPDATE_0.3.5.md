# 0.3.5 指定分頁收音面板

點擊工具列圖示後顯示控制面板，不再直接切換收音。面板列出一般影音網頁分頁，標示正在播放聲音的項目，並顯示目前收音來源。

目前分頁按「翻譯此分頁」開始；其他分頁按「前往所選分頁」，到達後重新點擊圖示授權並開始。任何分頁的面板都可按「停止收音」。選擇來源期間不會停止原本收音，直到啟動新來源。

新增 tabs 權限用來讀取分頁標題及網址並列出來源，清單僅用於擴充套件面板，不上傳後端。收音仍是單一分頁全部聲音，不是同頁單一播放器隔離。新增首次使用指引及明確錯誤訊息。

自動測試涵蓋面板啟動、停止、查詢來源、過期分頁拒絕與訊息來源限制。實際 Chrome 點擊授權及跨網站收音仍需真機驗收；未將模擬測試當作實播通過。

更新方式：Chrome 擴充功能頁重新載入本專案，確認新增權限，再重新整理影音頁面。原有提案中「再點圖示停止」的描述由本版面板停止按鈕取代。
