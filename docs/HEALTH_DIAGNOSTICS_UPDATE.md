# 健康狀態與診斷更新

日期：2026-09-12。依要求僅修改程式，不執行單元測試、推論測試或實播監控，亦未重啟服務。

- 後端 health 每十秒最多查詢一次 Ollama 模型列表（不產生推論）。分開回報 ASR 載入、啟動完成、翻譯服務及模型存在狀態。Ollama 不可用時 ready=false，保留 startup error 的原有語意，避免啟動器因運行期依賴中斷而反覆重載模型。
- 後端比較已載入程式指紋與磁碟檔案，提供 restart_required；擴充套件版本號相同並不能證明同版本程式已重新載入，面板明確提示。
- 即時管線錯誤記錄 VAD、ASR、翻譯排隊或翻譯階段，分類記憶體不足、逾時、連線、上游 HTTP 及其他處理錯誤。記錄最多三十筆於記憶體，並輸出結構化診斷到 stderr；不保留字幕或例外原文。
- 每分鐘記錄各階段最多六百筆數值，保留最多六十個活動分鐘。面板呈現辨識排隊、辨識、翻譯排隊、翻譯、排序等待及估计的語音起點至定稿呈現 P50/P95；缺失值不當成零。
- 啟動器每項服務最多自動重啟五次，避免設定錯誤時持續重載；用完後關閉其管理的子程序並提示人工處理。

限制：健康檢查證明連通與模型存在，不證明即時推論成功；分項耗時並不涵蓋全部瀏覽器呈現時間，不應直接相加作為完整端到端延遲。尚未新增自動模型切換，未調整翻譯模型或防幻覺閾值。本輪變更尚未測試，需重新載入後端與擴充套件才會生效。
